# Risk register

Reviewed at every retrospective.

| Risk | Likelihood | Response |
|---|---|---|
| Uncontrolled scope growth | Medium | Prioritise the pilot shop; every change goes through sprint planning |
| Verifactu complexity | High | Technical spike in I1; third-party API as fallback |
| Less availability during internships | High | Extra week for invoicing; critical tasks before 29 March |
| Limited experience with the stack | Medium | Learning in I0 and I1; technologies close to the syllabus |
| Loss of code or data | Low | Remote repository, protected branches and automatic backups |
| Loss of free cloud hosting | Low | Docker containers that can move to another provider |
